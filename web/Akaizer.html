How it works

This is a line-for-line port of the stretch routine inside the original Akaizer.exe (a Visual Basic 6 program from 2006), recovered from its machine code. The maths and quirks are unchanged:

  • The audio is cut into grains of 2 × cycle length samples, each shaped with a half-sine window.
  • Grains are laid down every sample rate ÷ cycle frequency samples and read from the input at that hop ÷ stretch. Overlaps are summed and hard-clipped to 16-bit, one grain at a time.
  • In linked mode the frequency is 41000 ÷ cycle length. The original uses 41000, not 44100.
  • Stereo files are processed interleaved, as in the original. Odd hop sizes can swap left and right between grains, which is part of the original's sound.
  • Output is a 16-bit WAV named yourfile_akaized.wav. Inside Claude it saves as a .zip with the WAV inside, because the viewer only allows certain file types. If you open this page as a local file, it saves the WAV directly.

Classic jungle trick: pitch a break up in your sampler or DAW first, then stretch it back to length here to get the metallic, granular texture.
